Connect your coach

The coach is Claude Code on your own computer. This site keeps your data and serves the coach's tools, so you install nothing but Claude Code.

Set up once

  1. Open Connect coach and press New token. Copy it: it is shown once.
  2. In any shell run the command that page shows: 
    claude mcp add --transport http coach {{ site }}/mcp --header "Authorization: Bearer <your token>"
  3. claude mcp list should show coach as connected.

Network blocks MCP? The Connect coach page also shows the local bridge command, which uses plain HTTPS.

Lost a laptop? Revoke its token on the same page. The coach on it stops working at once.

How a day runs

  1. Open this site and log in.
  2. Open Claude Code (desktop app or claude) in any folder. Type /coach.
  3. Come back here. Say "next" when the dot turns green.
  4. Work in the browser: approach, code, chat. Claude Code replies in the chat panel and waits again.
  5. Say you are done. The coach stops.

Check the dot

The dot in the discussion header is green and says Live when your Claude Code is waiting for you. If it says Offline, or the banner shows, your coach is not connected: open Claude Code and type the command again. It can take a few seconds to turn green.
