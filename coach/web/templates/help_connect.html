Connect your coach

The coach is Claude Code running on this machine. This site is where you work; Claude Code answers in the chat.

Install once

In any shell:

claude plugin marketplace add D:/Git/virtual457-projects/leetcode-coach
claude plugin install leetcode-coach@leetcode-coach-local

The skill is then /leetcode-coach:coach. Install it once only, or you get two coach servers.

How a day runs

  1. Run start.ps1 in the repo to start this site. Open it and log in.
  2. Open Claude Code (desktop app or claude) in any folder. Type /leetcode-coach:coach.
  3. Come back here. Say "next" when the dot turns green.
  4. Work in the browser: approach, code, chat. Claude Code replies in the chat panel and waits again.
  5. Say you are done. The coach stops.

Check the dot

The dot in the discussion header is green and says Live when Claude Code is waiting for you. If it says Offline, or the banner shows, the coach is not connected: open Claude Code and type the command again. It can take a few seconds to turn green.
